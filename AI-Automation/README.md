# AI Automation — Responsible Workflow

Learning concept:
1. Select an approved, non-confidential CSV report.
2. Use Python to calculate verified totals and trends.
3. Have a person review the metrics and context.
4. An AI tool may help draft a plain-language summary from those verified facts.
5. A person checks accuracy and approves the final report.

Safeguards:
- Never upload private customer, financial, student, or employer data without authorisation.
- Do not let generated text invent metrics or make decisions automatically.
- Keep a record of data sources and human review.

This is a learning concept, not a deployed production system.
