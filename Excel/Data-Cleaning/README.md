# Excel Data Cleaning and Reconciliation

## Workbook
`Cleaning-Data-Solution.xlsx` (original upload: `Cleaning Data Soln.xlsx`)

## Contents reviewed
The workbook contains four worksheets:

- **Supplier Invoice Statement** — invoice data preparation with text concatenation and extraction formulas.
- **MC Invoice Report** — invoice/report data with date and workday calculations.
- **Recon Analysis** — a compact reconciliation analysis sheet.
- **ASCII Table** — a larger text/table exercise.

## Skills demonstrated
- Combining and extracting text
- Parsing identifiers and invoice fields
- Working with dates and business-day functions
- Preparing information for reconciliation
- Reviewing tabular data for consistency

## Review note
The workbook includes many formulas. Formula presence was inspected, but every calculated result has not been independently validated. Check formulas and outputs in Excel before relying on the workbook for operational or financial decisions.
