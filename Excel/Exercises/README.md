# Excel Formula Exercises

This folder groups workbook exercises by the main Excel skills they demonstrate.

| Folder | Workbook | Topics |
|---|---|---|
| `Logical-Functions/` | `Exercise-01-Solution.xlsx` | Logical functions, conditional counts and sums |
| `Lookup-Functions/` | `Exercise-02-Solution.xlsx` | INDEX/MATCH, VLOOKUP, lookup results |
| `Sorting-Data/` | `Exercise-03-Solution.xlsx` | Sorting and arranging records |
| `Dynamic-Array-Functions/` | `Exercise-02-Answer.xlsx` | UNIQUE, FILTER, SORT, XLOOKUP, RAND |
| `Lookup-and-Logic/` | `Exercise-03-Answer.xlsx` | Two-way XLOOKUP, CHOOSE, SWITCH |
| `Statistical-Functions/` | `Exercise-04-Answer.xlsx` | AVERAGE, MEDIAN, MODE, LARGE, SMALL, RANK |
| `Rounding-and-Aggregation/` | `Exercise-05-Answer.xlsx` | ROUNDUP, MROUND, AGGREGATE |

These workbooks are practical learning exercises. Some formulas use newer Excel functions and may require Microsoft 365 or a recent desktop version.
