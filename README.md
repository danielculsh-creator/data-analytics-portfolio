## Featured projects

### [Sales Performance Analytics Dashboard — Power BI](PowerBI/README.md)

A three-page interactive report covering executive sales performance, product and customer analysis, and geographical and time trends. The PBIX report, page screenshots, and DAX reference are included in the repository.

### [Automobile Data Cleaning and EDA — Python](Python/automobile_data_cleaning_eda.py)

A beginner-level analysis of the UCI Automobile dataset using pandas and Matplotlib. The corrected script handles missing-value markers, converts numeric columns, reports data quality, and creates exploratory charts.

A Microsoft SQL Server practice script covering database and table creation, sample inserts, SELECT queries, UPDATE, and safe text storage for phone-number placeholders.

### [Excel Portfolio — Data Cleaning and Formula Exercises](Excel/README.md)

An index of Excel practice workbooks covering invoice reconciliation, HR data exercises, lookup and logical functions, dynamic arrays, sorting, statistics, rounding, and aggregation. Workbook redistribution is pending privacy and source-licence checks.

### [Sales Performance Analysis — Synthetic Practice Project](Projects/Sales-Analysis/README.md)

A reproducible practice project using a small synthetic sales dataset, with Python analysis and SQL queries. The sample is illustrative and does not represent a real company or real customers.

## Getting started

Install the project dependencies:

```bash
pip install -r requirements.txt
```

Run the sample sales analysis:

```bash
python Python/sales_analysis.py
```

Run the automobile analysis:

```bash
python Python/automobile_data_cleaning_eda.py
```

The automobile script downloads the dataset from the UCI Machine Learning Repository when run. It does not bundle a copy of the dataset.

The scripts are learning examples. Do not upload private, confidential, or personally identifying data.
