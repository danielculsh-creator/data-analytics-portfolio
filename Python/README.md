# Python Data Analysis

Beginner-friendly scripts for exploring business datasets.

## Run the sales summary
From the repository root:
python Python/sales_summary.py path/to/your_sales.csv

The input CSV may contain numeric columns such as revenue, cost, profit, or quantity. The script checks which columns exist and reports only available metrics.

Learning goals: read CSV files with pandas, inspect data types and missing values, calculate descriptive summaries, and explain limitations.
